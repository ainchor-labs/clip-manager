Clip Manager

A private tool for one creator's own channel.

Clip Manager is a self-hosted tool used by GooseMode to cut clips from GooseMode's own Twitch streams, schedule them as YouTube Shorts and videos on the same channel, and read that channel's view statistics to see which clips worked. It is not a public service: it runs on a private home server and only the channel owner signs in.

What it does with Google

  • Uploads the channel owner's clips to their own YouTube channel and adds captions and a comment to them.
  • Reads view, watch-time and subscriber statistics for that channel (YouTube Analytics).

See the privacy policy for how that data is handled.
